# Sources — discover-summer-camps

The seed source list. Curated, opinionated, and intentionally not exhaustive. **Scrape this list of campuses first**, then layer aggregators and forums on top.

The **drive-time numbers are rough** (Google-Maps-grade estimates with light traffic). Treat anything within ~15 minutes of the `max_drive_hours` ceiling as borderline — verify with a real route check before rejecting.

Add a new anchor or campus by appending to the relevant section below. Anchors not in this file should be added before running the skill against them; otherwise the geo filter has nothing to compare against.

## Aggregator sites (cross-cutting; mine these AFTER the per-campus pages)

| Source | URL pattern | What it's good for |
|---|---|---|
| **TeenLife** | `teenlife.com/program-types/summer-programs/` | Largest searchable directory; filterable by subject, grade, format. Many programs self-list with photos + reviews. Treat as **discovery only**, then verify against the program's official page. |
| **JKCF Summer Opportunities** | `jkcf.org/news/summer-opportunities-list/` | The **single most credible aggregator** — curated by the Jack Kent Cooke Foundation for high-achieving students. Mostly merit-based; flagged for scholarship eligibility. Updated annually. |
| **NACAC Summer Opportunities** | `nacacnet.org` — annual directory | Higher-ed-counselor curated. Less consumer-y than TeenLife. |
| **Pre-College Programs** | `precollegeprograms.org` / similar | Categorized by topic + selectivity. Verify currency. |
| **Niche pre-college lists** | `niche.com/colleges/best-summer-programs-for-high-school-students/` | Use with skepticism — populated heavily by SEO. Cross-reference, don't anchor on. |
| **CollegeXpress summer programs** | `collegexpress.com` | Self-listed; treat like TeenLife. |
| **US News "Best Summer Programs"** | annual ranking | Use for prestige cross-reference only. |

## Year-currency check

**Every program surfaced on the report must trace to a 2026-current source.** The official college program page is the ground truth. If only a 2024 listicle mentions the program and the official page doesn't list 2026 dates, drop the program with rejection_reason `not-verified-2026`.

The skill enforces this via the `source_year` field on each `sources[]` entry. The composite scorer down-weights programs without at least one `source_year=<run year>` entry, and the renderer hides them by default (toggleable in the appendix).

---

## Source rejection criteria (port from sibling skills)

- **AI content farms** — no author bio, no editor masthead, generic prose, identical phrasing across listicles.
- **SEO listicles** — "Top 20 Summer Programs!!!" with no editorial voice or selection rationale.
- **Stale archives** — older than ~2 years unless they're a historical reference (e.g., founding-year-of-program info).
- **Religious programs marketed primarily as faith formation** — surface but flag; this household isn't filtering on religion but the user should see the framing.
- **Online-only programs** — for this skill's purpose (on-campus summer experience), online doesn't count.
- **Sports-only camps** — out of scope unless the user explicitly opts in via `--interests sports`.
- **Programs with no clear dates listed for the search year** — they may not be running; investigate one level deeper before dropping. The official page sometimes hides the date in a PDF or a "request info" form.
